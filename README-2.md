# Mini Blog Deployment Logs & Troubleshooting

This repository documents the full terminal-based setup, execution, and troubleshooting process for deploying a **Mini Blog application** built using **Ruby + Sinatra**, and made publicly accessible via **Ngrok** on **macOS**.

## 📂 Repository Contents:

| File/Folder | Description |
|-------------|-------------|
| `README.md` | Structured overview of all key deployment steps with references to images |
| `mini_blog_terminal_report_grouped.docx` | Full report containing screenshots and step-by-step explanations |
| `images/` | Folder containing all 30+ annotated screenshots used for debugging and setup |

## 📑 Sections Included:

- ✅ **Installation** (Homebrew, Ruby via rbenv, Sinatra, CLI tools)
- 🚀 **App Execution** (`ruby app.rb`, Ngrok, Puma server)
- ❌ **Errors & Debugging** (permission issues, missing gems, Ngrok failures)

## 🔧 Ideal For:

- Software engineering students
- Beginners learning Sinatra deployment
- Debugging CLI issues on macOS
- Documenting Ruby environment setup workflows
